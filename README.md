# NSSP-Mini-project-1

The data file containing the original anatomical, functional and event files must first be downloaded from moodle and placed in the data folder, following the structure indicated in the first cell of `Project_notebook.ipynb`.

Then the notebook must be run in order to generate all figure and deliverable outputs (this takes a few minutes). The deliverable outputs are placed in the `data/derivatives` folder.

## Repository contents
 
 - **Code:** `T_code.ipynb`

 - **Report:** `T_report.pdf`

 - **Video:** `T_presentation.pdf`
